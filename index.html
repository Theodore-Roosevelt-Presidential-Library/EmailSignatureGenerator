New Outlook (the redesigned app on Windows and Mac, toggle in the top-right corner):

  1. Click Copy signature above.
  2. In Outlook, open Settings (gear icon) → Accounts → Signatures.
  3. Click + New signature, give it a name, and paste (Ctrl+V / ⌘V) into the editor.
  4. Under Select default signatures, choose it for new messages and replies. Click Save.

Not sure which Outlook you have? If there's a "New Outlook" switch in the top-right corner and it's on, you're here. If it's off (or there's no switch and you see a File menu), use the Classic Outlook tab.

Classic Outlook converts pasted logos into attachments, so don't paste — install the file instead:

  1. Click Download for classic Outlook (.htm) above. Save the file.
  2. Open File Explorer, click the address bar, paste %APPDATA%\Microsoft\Signatures and press Enter. (If the folder doesn't exist yet, open Outlook → File → Options → Mail → Signatures once, then try again.)
  3. Move the downloaded .htm file into that folder.
  4. In Outlook: File → Options → Mail → Signatures…. Your signature appears in the list — select it as the default for new messages and replies. Click OK.

If your Mac Outlook has a "New Outlook" switch turned on, follow the New Outlook tab instead.

  1. Click Copy signature above.
  2. Go to outlook.office.com → Settings → Mail → Compose and reply.
  3. Click + New signature, name it, paste into the editor, and click Save.
  4. Set it as the default for new messages and replies.

The Outlook mobile app only supports plain-text signatures (no logo or links).

  1. Click Copy plain-text version above and email it to yourself, or type it on your phone.
  2. In the Outlook app: profile icon → Settings (gear) → Signature, paste, and save.

Tip: if your organization has roaming signatures turned on in Microsoft 365, the signature you set in New Outlook or Outlook on the web will sync to your phone automatically.
