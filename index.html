New Outlook (the redesigned app on Windows and Mac, toggle in the top-right corner):

  1. Click Copy signature above.
  2. In Outlook, open Settings (gear icon) → Accounts → Signatures.
  3. Click + New signature, give it a name, and paste (Ctrl+V / ⌘V) into the editor.
  4. Under Select default signatures, choose it for new messages and replies. Click Save.

Not sure which Outlook you have? If there's a "New Outlook" switch in the top-right corner and it's on, you're here. If it's off (or there's no switch and you see a File menu), choose Start over and pick “It’s off.”

Classic Outlook converts pasted logos into attachments, so don't paste — install the file instead:

  1. Click Download for classic Outlook (.htm) above. Save the file.
  2. Open File Explorer, click the address bar, paste %APPDATA%\Microsoft\Signatures and press Enter. (If the folder doesn't exist yet, open Outlook → File → Options → Mail → Signatures once, then try again.)
  3. Move the downloaded .htm file into that folder.
  4. In Outlook: File → Options → Mail → Signatures…. Your signature appears in the list — select it as the default for new messages and replies. Click OK.

Apple Mail's signature editor strips the formatting and embeds the logo as an attachment when you paste. Instead, Mail's signature file gets written directly — it takes one pasted command.

  1. In Mail, go to Mail → Settings… → Signatures. Select your Library account in the left column, click +, and name the signature TRPL.
  2. In the editor on the right, delete everything and type exactly: TRPLSIG
  3. Uncheck Always match my default message font. At the bottom, set Choose Signature to TRPL. Close the Settings window.
  4. Quit Mail completely (⌘Q).
  5. Click Copy Apple Mail install command below. Open Terminal (⌘-Space, type "Terminal"), paste, press Return. It should say Done.
  6. Open Mail and start a new message — your signature is there.

The command finds the placeholder you typed, swaps in the real signature, and locks the file so Mail won't overwrite it. Mail's Settings preview may show the logo as a blank box (it doesn't load remote images there) — the sent message is correct. To update it later, quit Mail and run a freshly copied command — it finds the installed signature and replaces it.

The Outlook mobile app only supports plain-text signatures — no logo, no links. Use the text version.

Outlook on iPhone / iPad

  1. Click Copy plain-text version above, then email it to yourself (or open this page on your phone and copy it there).
  2. In the Outlook app, tap your profile picture (top-left) → the gear icon (bottom-left) → Signature.
  3. Delete "Get Outlook for iOS," paste your signature, and tap the back arrow to save.

Outlook on Android

  1. Get the plain-text signature onto your phone as above.
  2. In the Outlook app, tap your profile picture (top-left) → the gear icon → Signature.
  3. Delete "Get Outlook for Android," paste your signature, and tap the checkmark to save.

Apple Mail on iPhone: Settings → Mail → Signature, then paste the plain-text version. (Apple Mail can hold a pasted rich signature, but the logo is unreliable across recipients' apps — plain text is the safe choice.)

If your signature already appears on your phone, roaming signatures are turned on for the organization and the one you set in New Outlook or Outlook on the web is syncing automatically — nothing to do.
