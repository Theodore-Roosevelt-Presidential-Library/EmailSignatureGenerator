# TRPL Email Signature Generator

Live: https://emailsig.labs.trlibrary.com

A single-page tool that builds a brand-aligned email signature for Theodore Roosevelt Presidential Library staff. No build step, no dependencies — `index.html` is the whole app.

## How the logo stays a link (not an attachment)

The signature references the logo by absolute URL (`https://emailsig.labs.trlibrary.com/trpl-wordmark.png`). Whether it *stays* a link depends on the email client:

| Client | Method | Result |
|---|---|---|
| New Outlook (Windows/Mac), Outlook on the web | **Copy signature** → paste into the signature editor | Linked image ✅ |
| Classic Outlook (Windows) | **Download .htm** → drop into `%APPDATA%\Microsoft\Signatures` | Linked image ✅ |
| Classic Outlook (Windows) | Paste | ❌ Outlook re-embeds the image as an attachment — that's why the .htm route exists |
| Outlook mobile | **Copy plain-text version** | Text only (the app doesn't support images) |

Trade-off: recipients whose client blocks remote images will see a placeholder until they click "download pictures." That's the cost of keeping attachments out of every message.

## Files

- `index.html` — the app (form, live preview, copy/download, per-client instructions)
- `trpl-wordmark.png` — 312×187 logo on white, rendered at 156×94 (2× for sharp display). White background rather than transparent so it stays legible in dark-mode clients.
- `trplf-email-sig.png` — legacy 139×82 logo. **Keep it**: signatures generated by the old version of this tool still point to it.
- `CNAME` — custom domain for GitHub Pages

## Changing the signature

Edit the `Configuration` block at the top of the `<script>` in `index.html`: logo, footer links, colors, font. The signature markup itself lives in `buildSignature()` — tables and inline styles only, no CSS classes, no floats (email clients strip or ignore them).

## Deploy

Push to `main`. GitHub Pages serves it. Make sure **Enforce HTTPS** is on in the repo's Pages settings so the logo URL loads over https.
